= Bindings
Language-specific client bindings that wrap the gossamer C ABI for use from higher-level languages.
Current targets are `affinescript/` (AffineScript/Deno ESM) and `rust/`
(Rust crate); each subdirectory is a self-contained build unit. The Rust
binding's native-library delivery and verification contract is documented in
`rust/README.adoc`.
